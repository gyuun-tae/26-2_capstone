## 시험 20장에서 정한 것 (`data/catalog/vlm_sample_v1.json`, 미디어 질문셋·FAQ로 고르지 않음)

- 글자 이미지(절차·흐름도·카드뉴스·공고): 정확. 예) 분양 "공개경쟁입찰", 안전수칙 "LOTO", 공고 "9. 7.(월) 14:00".
  다만 "끼임→까임"처럼 글자를 틀리게 읽는 일이 있어 본문에 "AI가 글로 옮긴 것이므로 숫자·이름은 원문 확인 필요"를 붙인다.
- 큰 지도·도면: 같은 줄 반복으로 잘림(5/20), 회사명·지명을 지어냄(실행마다 다름), 항세도 대조군의 14kts·12kts 놓침.
  지시문 v2(Qwen 권장 샘플링·반복 줄 제거)로도 그대로 → **색인에 넣지 않고 사람 검수 목록**(`data/processed/vlm_review_queue.csv`)으로.
  핵심 도면은 원본과 대조해 `data/catalog/image_transcripts.json`에 옮긴다 (항세도와 같은 방식).

## 청크 나누기 — 게시글만 이미지별

| 시도 | 결과 (CPU 질의 임베딩, 로컬 색인, 재정렬 없이 상위 5) |
|---|---|
| 이미지 글을 본문 한 청크에 합침 | 카드뉴스 7장이 한 청크(2,000자) → 주제가 흐려져 i08(크루즈 터미널이용료) 5위 밖 |
| 모든 문서 이미지별 청크 | i08 **1위**. 그러나 안내 페이지 흐름도 청크가 자리를 차지해 h17(Port-MIS 정의)·t24 하락 |
| **게시글만 이미지별, 안내 페이지는 본문에 합침** (채택) | i08 1위 유지, h17·t24 회복 |

최종 색인 `bge-m3-dense-afcb8083efbe` (4,571 벡터) vs 서비스 중 `bge-m3-dense-7747f421d88d`:
개발 질문 11묶음 문서 적중·내용 포함 모두 같음, 하락은 d07(여수신항 선회장) 5위→6위 하나 — 재정렬 후보(15) 안.
측정 스크립트는 일회성(세션 scratchpad)이었다: 재정렬·판정·생성까지 넣은 측정은 GPU 서버로 `eval_local.py` 실행이 필요.

## 남은 일
