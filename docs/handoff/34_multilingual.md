# 34 V3 다국어 — 질문 언어 판별·고정 문구·화면 언어 선택 (2026-11-06)

## 왜

11/4 회의에서 V3 범위를 이미지·도면 + 다국어로 정했다. 다국어는 GPU 없이 할 수 있어 먼저 했다.
이전에는 "한글이 있나 없나"로만 외국어를 나눴고, 확인 불가 안내·대표전화 버튼·첫 화면은 한국어로만 나왔다.

## 바뀐 것

### 백엔드

| 항목 | 내용 | 파일 |
|---|---|---|
| 언어 판별 | 글자 종류를 세서 ko/en/ja/zh. 모델 호출 없음 | `src/api/app/lang.py` |
| 대화 언어 | 질문 언어 → (판단 불가면) 앞 질문 언어 → 화면 언어(`language`) → 한국어 | `lang.of_messages` |
| 고정 문구 | 확인 불가·GPU 꺼짐·날짜 안내·Port-MIS 안내 문장을 4개 언어로 | `lang.TEXT` |
| 버튼 | 대표전화·Port-MIS 버튼 이름을 대화 언어로. 부서·서식 이름은 공식 한국어 그대로 | `rag_real.localize` |
| 답변 언어 안내 | 외국어 대화면 "Answer in Japanese"처럼 언어 이름을 짚음 | `prompt.build_messages(language=)` |
| 외국어 페이지 | 외국어 질문이면 영·일·중 안내 페이지도 검색 후보 (판별만 lang으로 교체) | `search.is_foreign` |
| API | `ChatRequest.language` 추가 (선택: ko/en/ja/zh). 없으면 예전과 같음 | `schemas.py` |

판별 규칙 (`lang.detect`)

- 한글 음절 ×2 ≥ 라틴 글자 → 한국어 (`Port-MIS가 뭐예요?`는 한국어, `How do I get a 출입증?`은 영어)
- 가나가 있으면 일본어, 한자만 있으면 중국어 — 단 일본어 화면에서 한자만 친 글(`港湾施設使用料`)은 일본어
- 영문 한 단어(`TEU`)·숫자·한 글자는 판단 보류 → 앞 질문 → 화면 언어 → 한국어

대표전화는 **061-797-4300 유지** (11/6 결정. 4403은 공식 자료상 감사실 번호).

### 화면 (FE)

| 항목 | 내용 | 파일 |
|---|---|---|
| 언어 선택 | 헤더에 선택 목록(한국어·English·日本語·中文). 기본 한국어, 페이지 `<html lang>`이 en·ja·zh면 그 언어로 시작 | `ChatWidget.tsx`, `.langSelect` |
| 화면 문구 | 첫 화면·입력창·답변 화면·근거 패널·이용안내·오류·스크린리더 문구를 언어별 사전으로 | `src/widget/i18n.ts` (`useStrings()`) |
| 업무 카드 | 카드 이름·카드가 보내는 질문·예시 질문 4개 언어 | `tasks.ts` |
| 날짜·복사 | 원문 날짜 표시와 복사 글의 "참고자료" 제목도 화면 언어로 | `dateLabel.ts`, `parseAnswer.copyText` |
| 요청 | 화면 언어를 `language`로 함께 보냄 | `useChat.ts` |
| Port-MIS 링크 | 옛 `portmis.go.kr`(410 종료) → `new.portmis.go.kr` (백엔드와 같은 주소) | `tasks.ts`, `ScreenView.tsx` |

화면 언어는 답변 언어를 정하지 않는다. 영어 화면에서 한국어로 물으면 한국어로 답한다.
