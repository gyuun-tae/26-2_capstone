## 출력과 확인

`data/chunks/<doc_id>/<snapshot>/semantic-html-tables-v1/`에 저장한다.

- `chunks.jsonl`: 표 청크. 전부 보류된 문서는 빈 파일이다.
- `tables.json`: 원본 표·행·셀, 병합 범위, 셀 문자 위치와 격자. 구조 오류 표는 `geometry_error`를 기록하고 격자 값을 추정하지 않는다.
- `review.html`: 병합 셀을 보여주는 대조 화면. 보류된 표도 원문 그대로 표시하며 보류 사유를 붙인다.
- `review.md`: 생성된 청크 텍스트.
- `manifest.json`: 입력·출력 해시, 표별 행 범위 처리 상태.
- `data/chunks/_runs/tables-<시각>.json`: 실행 기록.

체육시설의 표 복원 결과를 브라우저로 여는 명령:

```powershell
$review = Get-ChildItem -Path ".\data\chunks\YGPA-005\*\semantic-html-tables-v1\review.html" | Sort-Object FullName -Descending | Select-Object -First 1
Start-Process -FilePath $review.FullName
```

확인할 핵심은 주간·야간/평일·주말 요금 연결, 최소 사용시간, 축구장 운영시간 예외다. 원문 빈칸은 0이나 해당 없음으로 바꾸지 않는다. 숫자·단위·조건은 보존하며, 의미 영향이 낮은 기호를 별도 정비하지 않는다.

## 청크 규칙과 팀 연결

1. 원본 본문 경계 안의 활성 HTML 표만 읽는다. HTML 주석·스크립트는 제외한다. 원본 HTML 해시와 기존 추출 해시가 검토 버전과 다르면 보류한다.
2. `rowspan`/`colspan`으로 격자를 복원한다. 다단 머리글·단위와 값을 연결하고 빈칸도 보존한다. 병합이 행 범위를 벗어나거나 격자에 누락·겹침이 있으면 보류한다.
3. 본문의 병합 셀이 이어지는 행들을 한 청크로 묶는다. 여러 선석의 공통 하역능력은 한 번만 기록하고 적용 행 범위를 명시한다. 행별 수치로 복제하거나 합산하지 않는다. 6,000자를 넘는 묶음은 임의 절단하지 않고 보류한다.
4. 체육시설 시간·요금 표에는 운영시간 예외, 예약 기한, 이용 유의사항을 붙인다. 선박 운항 표에는 선사 확인 안내를 붙인다. 광양지역 총괄에는 시설능력·컨테이너 하역능력 산정 제외 주석을 붙인다. 부두 표에는 원문 단위 및 해당 후속 주석을 유지한다.
5. `source_locator.kind=html_table`: 원본 HTML 경로·인코딩·표 문자 범위, 0부터 시작하는 행 범위(끝 제외), `cell_ids`, `header_cell_ids`를 제공한다. `tables.json`의 셀은 원본 HTML 내 문자 범위를 가진다. HTML은 줄바꿈을 바꾸지 않은 디코딩 문자열의 Unicode codepoint 위치다.
6. `context_locators`는 CRLF→LF 정규화한 기존 `document.txt`의 예외·주석 위치다. 표 청크는 구조를 풀어 쓴 텍스트이므로 원문 전체에서 연속된 문자열 하나를 잘라낸 청크와는 다르다.
7. `extraction_version=html-table-grid-v1`, `source_extraction_version`은 기존 본문 추출 버전, `chunking_version=semantic-html-tables-v1`이다. `chunk_text_sha256`은 생성 텍스트 해시다. 공통 출처·날짜·문서 버전 필드는 유지한다.
8. 검색 담당자는 기존 `semantic-v1`/`semantic-html-v1` 설명 청크에 이번 표 청크를 같은 문서·snapshot 기준으로 연결할 수 있다. 원본별 채택 버전을 명시하고 `chunk_id`로 중복을 판별한다. 조건 보존을 위한 일부 텍스트 반복은 의도된 것이다. 이전 manifest의 보류 범위를 이번 실행이 전부 해결한 것으로 처리하지 않는다.
9. 모든 청크는 `index_approved=false`인 검토 전 초안이다. 최신 요금·운항 여부·규정 유효성을 확인한 결과가 아니다. 원본·본문·기존 청크는 변경하지 않고 동일 출력 재실행은 유지, 손상 출력은 보류한다.

검증: 합성 표 테스트 9건을 포함한 전체 75건 통과. 실제 10건에서 표 셀 개수·원본 문자 위치·본문 행의 누락/중복 없는 처리·조건 인용 위치·임시 저장/재실행을 확인했다. 최신 데이터 조회나 웹 요청은 하지 않았다.

Git에는 이 코드·테스트·안내만 추가하며 생성된 표·청크는 기존 제외 규칙을 따른다. 코드 업데이트는 검증 후 커밋하고 `origin/main`에 강제 push 없이 반영한다.
