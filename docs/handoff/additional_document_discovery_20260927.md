## 단계와 결론

사용자 요청의 1단계인 후보 탐색 결과다. 기존 `YGPA-001~020`에 들어 있지 않은 첨부 문서 후보 21건을 찾았다. 민원서식자료실의 게시글 14개에서 작성 예시를 제외한 HWP 16건, 이용규정 안내의 국문 규정 4건, 기존 체육시설 안내에 연결된 신청서 1건이다. 탐색 번호는 임시 번호이며 공식 doc_id를 새로 발급하지 않았다.

현재 수집·추출 완료 문서는 기존 20건이다. 이번 21건은 신규 수집 완료 건수가 아니다. 기존 CSV·URL 정책·코드·원본·처리 문서는 변경하지 않았다. 다음 단계는 후보 CSV 등록과 허용 URL 정책 정비이며, 청크화는 보류한다.

## 확인 수준과 보류 사항

- 탐색-01~16: 공개 게시글 상세 HTML에서 제목·작성일·첨부 파일명과 다운로드 URL을 확인했다. 파일 본문은 다운로드·추출하지 않았다. 2015~2021년에 게시된 자료이므로 현행 서식 여부를 확인하기 전 최신 신청 요건의 근거로 승인하지 않는다.
- 탐색-17~20: 공식 이용규정 HTML에서 규정명과 직접 다운로드 URL을 확인했다. 페이지의 `cont_last_mdfcn_dt` 표시 코드에는 2026-08-18이 있으나 이를 개별 규정의 개정일·시행일로 사용하지 않는다.
- 탐색-21: 사용자가 2026-09-23 저장한 YGPA-005 HTML에서 신청서 안내와 첨부 URL을 확인했다. 첨부 버튼 표시는 '첨부파일'이므로 실제 파일명은 아직 미확인이다.
- 탐색-17~21의 다운로드 URL은 HEAD 요청에 HTTP 405를 반환했다. 서버가 HEAD 방식을 지원하지 않는다는 뜻이며 파일이 없거나 GET 다운로드도 불가능하다는 뜻은 아니다. 실제 다운로드 가능 여부는 별도 확인 대상으로 남긴다.
- 민원서식자료실은 웹 열람 도구에서 목록이 비거나 상세 접근 오류가 났지만, 직접 HTTP 조회로 목록 및 상세 화면을 확인했다. 도구 오류를 사이트 접근 불가로 분류하지 않았다.
- 기존 후보 CSV의 20개 source_url과 이번 첨부 URL은 다르다. 다만 내용 중복은 첨부 확보 후 해시와 본문을 대조해야 확정할 수 있다. 'URL 비중복'을 '내용 비중복 검증 완료'로 표시하지 않는다.

## 다음 수집·추출 담당자에게 전달할 사항

- 민원서식은 게시글 HTML과 첨부 HWP가 다른 자료다. 상세 화면의 '신청서 양식입니다' 문장만 추출한 것을 신청서 내용 확보로 간주하지 않는다.
- 파일 다운로드 호스트가 공식 호스트라는 이유만으로 모든 file_no를 허용하지 않는다. 위 부모 페이지에서 확인한 첨부 URL만 승인 목록으로 추가한다. FAQ 첨부도 같은 다운로드 경로를 쓸 수 있기 때문이다.
- 게시판 HTML에는 본문 시작 주석이 중첩되고 이전글·다음글·인증 폼이 들어 있다. 기존 일반 HTML 추출기의 주석 경계만 사용하지 말고 게시글의 제목·작성일·본문·첨부 영역을 분리한다.
- HWP의 표와 빈 입력 칸, 제출 대상, 서명·동의 항목을 구조와 함께 보존한다. 그림이나 OCR이 필요한 문서는 별도로 표시한다.
