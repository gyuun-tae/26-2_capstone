## 우선 보완할 사항

1. **HWP 11건: 표 구조 복원.** YGPA-021 한 건부터 셀의 행·열·병합 정보와 문단 연결을 추가하고 결과를 대조한다. 전체 HWP로 확대하기 전에 숫자·단위·서명/입력란의 대응을 확인한다. 원본에서 빈 입력란을 값이 없는 실제 신청 내역으로 해석하지 않는다.
2. **YGPA-030: 위치도 이미지 누락.** `BinData/BIN0001.jpg`는 별지3 항계밖 정박지 위치도다. 구역·항로·지명의 공간 관계는 현재 텍스트에 반영되지 않는다. 이미지 근거 관리와 별도 검수가 필요하며 OCR만으로 경계를 추론하지 않는다.
3. **YGPA-031: 도면 보완 범위를 26~29쪽으로 확대.** 앞 단계에서 28~29쪽만 표시했으나, 이미지 점검을 통해 26~27쪽의 야적장 위치도도 확인했다. 추출기는 페이지 제목만 얻고 그림 안의 시설명·면적·치수를 대부분 놓친다. 원본 그림과 대조한 OCR/주석이 필요하다.
4. **YGPA-032: 9쪽 특수문자 2곳.** U+F000이 규정명 앞뒤에 있다. 정확한 기호가 확인되기 전에는 일괄 삭제·괄호 치환하지 않는다. 원본 글꼴과 수정 근거를 확인할 항목으로 남겼다.
5. **YGPA-032: 기한부 감면 조건.** 시각 확인한 20·23쪽에 2024년 12월 31일까지라는 조건이 있다. 이 문서를 2026년 현재 기준으로 자동 사용하지 않는다. 공식 현행본·시행일 검증 또는 과거 자료 분리가 필요하다. 이번 검토는 현행 법적 효력의 판단이 아니다.

032의 17쪽 단위 환산표와 20·23쪽 감면표는 대표 수치·단위·비율이 추출문에 남는 것을 확인했다. 하지만 열 머리글·감면율·조건의 관계를 재구성하지 않았으므로 표 검수가 끝난 것은 아니다.

## 검토 증거와 팀 연결

- 원본과 document.txt/document.json/blocks.json은 변경하지 않았다. 청크화·색인·FAQ 수집은 하지 않았다.
- 로컬 상세 기록: [review.json](../../data/processed/_reviews/attachments-20260927/review.json). 각 문서의 원본 버전 해시, snapshot, 검증 결과, 보완 사유를 포함한다.
- 같은 검토 폴더의 hwp_comparison.json, pdf_page_audit.json은 구조 대조 기록이다. `reference_tables/`는 별도 도구가 해석한 표의 행·셀·병합 정보를 대조용으로 보관한다. 검색·학습 입력으로 쓰지 않는다.
- 별도 변환 도구는 이번 검토의 임시 도구다. 프로젝트 의존성에 추가하거나 소스를 복사하지 않았다. 공식 원본 지면 렌더와 동일하다고 보장하지 않는다. pyhwp의 변환 기능은 [프로젝트 문서](https://pyhwp.readthedocs.io/en/latest/intro.html)를 참고했다.
- GitHub에는 이 검토 요약과 실행·규격 문서를 공유한다. 표 텍스트를 포함한 상세 대조 기록은 data/processed 아래에 있어 기존 Git 제외 규칙이 적용된다.
- 문서 처리 담당자는 보완 후 새로운 처리 버전을 만들고 원본과 대조한다. 검색 담당자는 승인 전 자료를 색인하지 않는다. 평가 담당자는 FAQ를 계속 별도 관리한다.
