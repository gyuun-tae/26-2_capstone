# 개발용 질문 기대값 검토 요청 (2026-10-13)

받는 사람: 업무·자료 담당. 작성: 백엔드(API·답변 제어).

개발용 질문 묶음(`evaluation/datasets/dev_questions_*.jsonl`, 141문항)의 기대값은 백엔드가 **초안**으로 적었다.
챗봇 답을 바꿀 때마다 이 기대값으로 맞고 틀림을 세기 때문에, 기대값이 틀리면 좋은 답을 "실패"로 세거나 나쁜 답을 놓친다.
아래 항목만 봐 주면 된다. 각 항목에 **동의 / 다르게 / 모름** 중 하나와 이유 한 줄을 적어 주세요 (이 파일에 직접 또는 노션 댓글).

## 기대값 항목 뜻

| 항목 | 뜻 |
|---|---|
| `expect_type` | 허용하는 답 유형: answer(답함) · clarify(되물음) · unknown(확인 불가 + 대표전화) |
| `expect_docs` | 근거 상위 5개 안에 있어야 할 문서 (하나라도 있으면 통과) |
| `forms_allowed` | 다운로드 버튼으로 붙어도 되는 서식 문서. 여기 없는 서식 버튼이 붙으면 실패 |
| `must_mention` | 답에 꼭 있어야 할 말 (`A\|B`는 둘 중 하나) |

|---|---|---|---|
| r01 | 기상 악화로 입항이 지연되었을 때 지체료나 정박료가 면제되는 조건이 있나요? | answer, "기상" 언급 | 사용료 규정 별표 2의 기상악화 통제선박 감면 |
