# 데이터 처리 체크포인트 — 2026-09-28

YGPA-030의 표·그림 검토 화면 안내 후 사용자가 “오케이 확인함”이라고 응답했다. 확인 범위는 표 표시, 두 번째 표의 개체 링크, 내장 지도 및 ‘통과선박’, ‘정박지’ 텍스트 표시다. 원본 도형의 시각 배치를 재현하거나 의미·현행성을 승인한 기록은 아니다.

## 실제 저장 상태

- data/raw와 data/processed에 YGPA-001~033 문서 폴더가 각각 33개 있다. 수집·본문 추출 완료 보고와 일치한다. 이 수치는 본문 내용의 최종 검수 완료를 뜻하지 않는다.
- HWP 11건의 표 구조는 총 52개 표·1,930개 셀이다. 현재 결과 파일의 해시를 모두 확인했다.
- YGPA-021~029: hwp-tables-v1
- YGPA-033: hwp-tables-v2, 겹친 글자 ① 별도 보존
- YGPA-030: hwp-graphics-v1, 표 3개·셀 58개·그림 1개·개체 내부 문단 2개·원본 레코드 35개 보존
- HWP 파생 결과 11건의 index_approved=false를 확인했다. 청크화·검색 등록은 아직 수행하지 않았다.

## 사용자 확인 범위

| 문서 | 확인 상태 |
|---|---|
| YGPA-021 | 표·빈칸·병합·중첩 표 대조 안내 후 문제 제보 없음 |
| YGPA-022~029 | 자동 구조 대조·저장 무결성 확인. 각 문서의 사용자 육안 대조 완료 응답은 아직 없음 |
| YGPA-033 | 겹친 글자를 포함한 표 화면·원문 대조 확인 완료 |
| YGPA-030 | 자료 표시·연결 확인 완료. 지도와 도형의 원본 배치 재현은 미완료 |

각 확인은 해당 원본 snapshot과 파생 버전에 한정한다. 원본·기존 본문·validation.json의 상태를 사용자 확인만으로 변경하지 않았다.

## 남은 작업

1. YGPA-030: 지도에 얹힌 선·도형·글상자의 원본 배치 대조/재현. 내장 JPEG만으로 최종 지도를 대체하지 않는다.
2. YGPA-031: PDF 26~29쪽 도면을 페이지 단위 근거로 보존하고 원문과 대조. 도면 내부의 시설명·수치·면적은 현재 일반 본문만으로 충분하지 않다.
3. YGPA-032: 9쪽 특수문자, 표의 행·열 관계, 기한부 조건, 문서 현행성 검토. 기존 검토 항목은 미해결 상태다.
4. YGPA-022~029: 원문 육안 대조. 전체 문서의 날짜·개정 상태·사용 범위 검토도 별도로 필요하다.
5. 위 보완 후 청크 설계와 승인 범위를 정한다. 사용자가 청크화를 미뤄둔 요청을 유지한다.
6. GitHub 저장소 생성·공유 파일 검토·push는 아직 진행하지 않았다.

다음 작은 실행 단위로는 YGPA-031의 도면 4쪽 보존을 진행할 수 있다. 이것이 YGPA-030의 배치 재현 보류를 해소했다는 뜻은 아니다.

## 팀 인수인계

자료·문서 처리 담당자는 이 체크포인트와 각 실행 안내를 기준으로 이어간다. 검색 담당자는 현재 결과를 승인된 검색 근거로 간주하지 않는다. FAQ는 최종평가 전용이며 이번 작업에서 접근·수집하지 않았다. 모델의 기존 사전학습 포함 여부에 대한 보장은 하지 않는다.

코드·테스트·인수인계 문서는 Git 공유 대상이다. 원본·파생 결과·지도 이미지는 기존 .gitignore의 data/raw 및 data/processed 제외 범위에 둔다.
