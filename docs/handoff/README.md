# 담당별 인수인계 안내

## 작업을 전달할 때 남길 내용

1. 담당자와 완료한 범위
2. 입력 파일·필드와 출력 파일·필드
3. 설치 조건과 프로젝트 루트 기준 실행 명령
4. 실행에 필요한 환경변수 이름과 예시 값 — 실제 비밀키 제외
5. 확인한 결과, 실패 사례, 아직 확인하지 않은 부분
6. 다음 담당자의 시작 위치와 남은 작업

## 데이터 담당 → 문서 처리·검색 담당

문서 후보 CSV·Markdown, 승인된 수집 대상, 원본 파일 위치, 문서 ID, 수집 시각·성공 여부, 날짜 불명확·접근 불가·표 추출 주의사항을 전달합니다. 원본이 Git에 없더라도 동일 자료를 확보할 수 있도록 수집 방법을 함께 기록합니다.

## 문서 처리·검색 담당 → API·평가 담당

출처와 버전이 연결된 청크, 색인 생성 방법, 예시 질문과 검색 결과, 추출 오류·검토 상태를 전달합니다. 미검토 문서를 사용 가능한 근거로 자동 승인하지 않습니다.

## API 담당 ↔ 화면 담당

실제 서버 완성 전에도 같은 예시 응답을 사용합니다. 답변·조건 확인·확인 불가·오류 및 인용 근거 표시를 함께 확인합니다. 공통 형식을 바꾸면 `docs/contracts/`와 예시 응답을 함께 갱신합니다.

## 평가 담당 ↔ 개발 담당

개발용 질문과 근거를 공유하고, 최종평가 질문·정답은 별도 보관합니다. 같은 질문의 바꿔 쓰기가 개발·최종평가 양쪽에 섞이지 않게 관리합니다. 결과에는 문서·청크·모델·설정 버전을 남깁니다.

## 배포 담당 ← 전체 팀

각 기능의 실행 명령, 의존성, 필요한 환경변수 이름, 데이터 확보·색인 복원 방법을 모읍니다. GitHub 공유 전 비밀키와 대용량 생성물의 제외 상태를 확인합니다.

## HTML 청크화 확대 (2026-09-29)

[현재 실행·처리 범위·팀 연결 규격](chunking_html_batch.md)을 따릅니다. HTML 19건을 검사하여 13개 문서에서 15개 초안 청크를 준비합니다. 나머지 6개 문서 및 일부 표 범위는 명시적으로 보류합니다. FAQ 제외, 원문 위치 추적, index_approved=false를 유지합니다.


## HTML 표 청크화 (2026-09-29)

[표 청크 실행·규격](chunking_html_tables.md): 설명 청크 16개 실제 저장 확인 후, 표 14개의 구조를 보존하는 청크 54개를 준비했습니다. source_locator.kind=html_table 및 context_locators로 원본 셀·조건을 연결합니다. 표가 일부 보류됐으므로 전체 문서 완료나 검색 승인으로 해석하지 않습니다.


## 현재 첨부 청크화 단계 (2026-09-29)

HTML 청크 70개 실제 저장 확인. [첨부 13건 청크화 실행·규격](chunking_attachments.md)에서 108개 추가 청크를 준비했습니다. source_locator.kind=attachment_composite로 문단/페이지/표를 연결합니다. 부칙은 과거 적용 규정 표시를 붙이며 PDF 별표·도형 배치는 보류합니다. 코드·설명 문서 갱신 후 커밋·main push까지 수행합니다.


## 첨부 청크 실제 저장 확인 (2026-09-29)

첨부 108개 저장 완료. HTML 70개와 합쳐 31개 문서에서 총 178개입니다. 출력 해시·개수·ID 고유성·검색 미승인 상태를 확인했습니다. [최신 저장 기록](chunking_attachments.md)을 따릅니다. YGPA-002·013 및 일부 표·도형·날짜 검토는 남아 있으며, 다음 단계는 보류/검수 결과에 따라 검색용 청크와 채택 버전을 확정하는 것입니다.
