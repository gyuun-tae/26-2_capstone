# 27 법령 서식 청크 · 이어지는 질문 재검색 · "[근거]" 이름표

2026-10-07. 팀 시연 준비 중 사용자 시험에서 나온 문제를 고쳤다.

## 문제

1. "출입 신고서는 어디서 볼 수 있어?" → "관리청에 제출"만 답하고 Port-MIS·서식 위치가 없었다.
   - 출입 신고서는 YGPA 사이트 서식이 아니라 선박입출항법 시행규칙 **별지 제1·2호서식**이고, 실제 신고는 Port-MIS 입력이다.
   - 23번 법령 청킹에서 서식(별지)을 모두 뺐기 때문에 서식 이름·내려받을 곳이 데이터에 없었다.
   - 운영규정 제5조(YGPA-031, "출입신고서로 Port-MIS에 입력")는 벡터 검색 24위라 근거에 들지 못했다.
2. 이어서 "이 사이트에서 서식을 얻을 수 없는거야?" → 확인 불가.
   - 15자 이상이라 앞 질문 없이 혼자 검색 → 1위 0.45 < 기준 0.48 → LLM을 부르지 않고 unknown.
3. 답에 지시문 이름표 `[근거]`가 그대로 보였다("[근거]에 따르면", "[근거]에 … 없습니다").

서식 청크 내용: `[별지 제n호서식] 이름` · 「법령」 서식, 서식 파일(HWP)은 국가법령정보센터 · 근거 조문(그 서식을 정한 조문) ·
온라인 신청 안내(서식에 있으면) · 작성 항목 앞부분 700자. 서식 전문(상자 문자 표 수천 자)은 넣지 않는다.

- 넣는 서식: 민원인이 작성·제출하는 것. 이름이 증·증명서·통지서·지정서 등으로 끝나는 기관 발급 문서(영문 병기는 떼고 판단)와 삭제 서식은 뺀다.
- 다운로드 주소: `https://www.law.go.kr/LSW/flDownload.do?flSeq=…` (API의 별표서식파일링크, HWP 응답 확인).
- 서식에 적힌 `www.portmis.go.kr`은 닫힌 옛 주소(410)라 "항만운영정보시스템(Port-MIS)"으로만 적는다. 두 단 배치로 잘린 주소 조각도 뺀다.
