# 31 답변 전 판정(gate) + 재정렬 다시 켜기 준비 — 기본은 계속 끔

2026-10-09~10. 색인 `bge-m3-dense-2e26c2fc2e81`. 코드는 `main`에 들어가지만 **`RAG_GATE`·`RAG_RERANK` 기본값은 off**라
지금 서비스 동작은 그대로다(아래 "지금 서비스에도 적용되는 것" 제외). 켜는 방법은 맨 아래.

## 왜

재정렬(28번)은 1위 정답을 늘렸지만, 관련 있어 보이는 청크가 위로 오면 LLM이 확인 불가 대신 답하거나 엉뚱하게 되물어서
(u02 "부산항 운영사", u04 "해상 운임") 꺼 두었다. 그래서 답을 만들기 전에 **"근거가 질문의 주제를 다루는가: 있음/없음"**만
따로 묻고, 없음이면 확인 불가 + 대표전화로 보낸다 (`src/api/app/gate.py`).

## 구성

```text
질문 → 임베딩 → 후보 20 → 확인 불가(벡터 0.48) → 재정렬(앞 10개, 1024토큰) → 근거 5개
                                                         ├─ 답변 생성 Qwen3-32B (GPU 1번) ─┐
                                                         └─ 판정 gate-llm = Qwen3-14B (GPU 0번) ─┴→ 있음: 모아 둔 조각부터 내보냄 / 없음: 생성 멈추고 확인 불가
```

| 무엇 | 어디 |
|---|---|
| 판정 모델 `Qwen/Qwen3-14B-AWQ`, vLLM, GPU 0번(BGE-M3·재정렬과 나눠 씀, 메모리 0.55), `127.0.0.1:8103`, 이름 `gate-llm` | `infra/gpu_server/start_gate.sh` |
| 관문: `/v1/chat/completions`를 모델 이름으로 나눔 (`qwen3-32b`→8100, `gate-llm`→8103). `/health`에 `gate` 표시(꺼져도 200) | `gateway.py`, `check_gateway.py` |
| 판정·생성 동시 실행, 판정 전 조각은 화면에 보내지 않고 모아 둠(`hold`). 판정 실패·8초 초과·판정 모델 꺼짐이면 판정 없이 답함 | `app/gate.py`, `rag_real.py` |
