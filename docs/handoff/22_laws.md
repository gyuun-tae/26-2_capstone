# 22·23 법령·고시 수집과 조문 청킹

2026-10-03. 인천항만공사 'AI 규정 비서'(사규+항만법 등, 조항 근거 제시)와 비교했을 때 가장 큰 차이가 법령 근거가 없다는 점이라 1단계 법령·고시를 넣었다.

## 출처와 범위

- 국가법령정보 공동활용 Open API(https://open.law.go.kr). 인증값은 저장소 루트 `.env`의 `LAW_OC`(Git 제외). API 신청 시 등록한 IP(학교 네트워크 168.131.194.121, GPU 서버 168.131.154.224)에서만 동작한다.
- 대상 목록: [law_sources.json](../contracts/law_sources.json). 법령·고시는 저작권법 제7조에 따라 보호 대상이 아니다.
- 1단계(11건): 항만법·항만공사법·선박입출항법(각 법·시행령·시행규칙, 항만공사법은 시행규칙 포함), 해수부 고시 「무역항 등의 항만시설 사용 및 사용료에 관한 규정」, 「항만공사가 징수하는 사용료 및 임대료의 세부 구분 등에 관한 규정」.
- 2단계 후보: 위험물 선박운송 및 저장규칙, 자유무역지역법(법·령·규칙, 시행규칙은 산업통상부), 항만안전특별법, 항만운송사업법. `law_sources.json`에 tier 2로 추가하고 `--tier 2`로 받는다.

## 실행

```bash
python scripts/22_collect_laws.py             # 현행 버전·변경 여부만 확인 (네트워크)
python scripts/22_collect_laws.py --download  # 바뀐 것만 data/raw/LAW-xxx/<스냅샷>/ 에 저장
python scripts/23_chunk_laws.py               # 최신 스냅샷 → data/processed, data/chunks (오프라인)
python -m unittest tests/test_chunk_laws.py
```

- 개정 확인: 22번을 다시 돌리면 버전 번호(법령 MST, 고시 일련번호)를 직전 스냅샷과 비교해 `그대로/변경`을 보여 준다. 변경분만 받고 23번 → 색인 재생성.
- API 응답의 상세 링크에 들어 있는 OC는 저장 전에 `OC_REMOVED`로 바꾼다. 저장 후 원본에 OC가 남았으면 멈춘다.

## 청킹 규칙 (`law-articles-v1`)

| 항목 | 처리 |
|---|---|
| 조문 | 조문 하나 = 청크 하나. 항 → 호 → 목을 줄 단위로 펼친다 |
| 긴 조문 | 2,500자(근거 상한 3,000자보다 작게)를 넘으면 항 경계(항이 없으면 호)에서 나누고 뒤 조각 첫 줄에 `제n조(제목) (계속)` |
| 장·절 제목 | 본문이 아니라 `section_titles`에. 개정 표시(`<개정 …>`)는 지운다 |
| 고시 본문 | 항·호가 줄바꿈 없이 붙어 오므로 ①~⑳과 `n. ` 앞에서 줄을 바꾼다. 날짜 `2026.1.1.`의 끝자리는 호 번호로 보지 않는다 |
| 별표(표) | 상자 문자 표의 가로 테두리 = 행 경계. 테두리·빈 칸 줄은 지우고 칸막이(┃│)는 남긴다. 행 묶음 단위로 2,500자 안에서 나눈다. 링크는 별표 PDF |
| 제외 | 부칙, 내용이 `삭제`뿐인 조문, 서식·별지(빈 신청서), 제개정이유. 항만법 시행령 별표 1(전국 항만 수상구역 좌표 약 5만 자)은 `annex_held`로 보류 |
| 출처 링크 | 법령 조문은 `https://www.law.go.kr/법령/<법령명>/제n조`(조문으로 바로 열림), 고시는 고시 전체 페이지 |
| 날짜 | `published_at`=공포(발령)일, `effective_at`=시행일, `date_status=official_api_current`. 근거 블록에 `(시행 YYYY-MM-DD)`로 표시 |
| 위치 표시 | `source_locator.kind=law_api`, 화면 위치 문구는 `article_label`(예: `제41조(항만시설의 사용)`, `[별표 1] …`) |
| 승인 | 모두 `index_approved=false`, `review_status=draft_pending_chunk_review` |
