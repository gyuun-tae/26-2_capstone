### 제외 규칙

- FAQ(`/faqs/`, `bbs_no=230`) — 경로 차단, 첨부는 해시로 차단
- 회원·예약 달력·신고 입력 화면, 사용자 글 게시판(자유게시판·문의)
- 사전정보공표·경영공시 세부(업무추진비·계약·재무) — 항만 이용 안내와 무관, 양이 많아 검색을 흐림
- 선석 배정표·정박지 대기 — 매일 바뀌는 현황
- 공고·채용 — 기한이 짧음

- `new.portmis.go.kr` — robots.txt가 전체 금지
- 해양수산청: 어업·등대 체험·정보공개 메뉴

## 처리 규칙 (29번)

- 본문 경계: 한국어는 25번과 같은 "X(Twitter) ~ 담당자 만족도 평가", 외국어는 `<div class="contents">`, 해양수산청은 `sub-content ~ satis-cont`만 저장
- 여러 문서에 5번 넘게 반복되는 짧은 줄(탭 메뉴)은 뺀다. 표 머리글(`|`·`—` 포함 줄)은 남긴다 — 처음엔 부두 표 머리글이 지워져 값의 뜻이 사라졌다
- 이미지: 사진 설명 alt("사진", "모습", "전경" 등)는 검색 잡음이라 뺀다. 해양수산청 항세도 alt가 "인천항·경인항"으로 잘못 적혀 있어 다른 항만 이름 alt도 뺀다
- OCR은 글자 20자 이상, 한자 2% 미만, 한글·영숫자 75% 초과일 때만 쓰고 "(이미지에서 자동으로 읽은 글자이므로 원문 확인 필요)"를 붙인다 → `ocr_text_unverified`
- 사람이 원본과 대조해 옮긴 글: [image_transcripts.json](../../data/catalog/image_transcripts.json) (이미지 SHA-256 → 글). 항세도 2장·도선사 승하선구역도
- 게시글은 본문 첫 줄에 게시일, `time_sensitive_notice`
- 페이지 아래 담당 부서·전화 → `contacts.json`의 `site-` 항목 (답변 근거 문서의 담당 버튼)
